### 23:32 UTC: Approval notifier outbox (`feat/notifier-outbox`)

- Table `notice_outbox` in the lease store's database (created at open, like `run_spans`): id, `event_id` (unique), type, approval id, the body as sent, created time, attempts, next try, delivered or given-up time, times in Unix milliseconds. The SQL is in `attenuo-audit` (`sqlite/outbox.rs`, inherent methods of `SqliteLeaseStore`, under its write gate); the notifier now takes the concrete store.
- When rows are written: the producers (`NotifierHandle::pending` and `decided`, and the expiry watcher) insert the row right after the approval change and its audit record, then queue the notice. One local insert on a thread that already wrote twice, never the network. Not in the approval's transaction, because the approval is written before its audit record and removed again when the append fails. An insert that fails falls back to memory only, with a warning.
- Delivery still runs from the in-memory `sink::Queue`. A new `sink::Settle` hook marks the row delivered, given up (after `max_attempts`, or when dropped from a full queue), or records the failed attempt and the next try. ### 04:40 UTC: One host grammar for limits (`fix/derive-host-bare`)

Step 1 of section 6 of the [read-side exfiltration](../design/read-side-exfiltration.md) note. `Derive::Host` refused a bare host, because `url::Url::parse` needs a scheme, so on AgentDojo slack, where every URL is a bare host, a host limit refused every fetch with `limit_arg_invalid` and `destination = "url#host"` counted raw strings.

- `Derive::Host` reads a value with no scheme as `http://` followed by the value. No scheme means `url::Url::parse` refuses it as relative (`RelativeUrlWithoutBase`), or reads a non-special scheme whose `:` is followed by one or more digits up to the first `/`, `?` or `#`: a host name is also a valid scheme name, so `localhost:8080` and `a.example:443/x` are a host and its port. A special scheme still wins (`http:8080`), any other scheme stays refused (`mailto:`, `javascript:`, `data:`, `a.example:x@b.example`), a value starting with `/` has no host, and the SR-56, FZ2-1 and FZ2-2 guards are unchanged. `good.example@evil.example` counts `evil.example`, the host a browser would connect to.

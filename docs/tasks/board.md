- [ ] `onbehalf-audit` (fuzzing F5): decide whether `verify_export` should fail an export holding entries after its header's `to`. Reproducer: `audit_export_mutated` input `[AppendEntry { rehash: true }]`; set `ONBEHALF_FUZZ_STRICT_EXPORT_RANGE=1` to make the target check it.

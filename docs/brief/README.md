# Researcher brief

[`attenuo-one-page.md`](attenuo-one-page.md) is a one-page summary of attenuo (problem, design, headline evidence, three open research questions) for attaching to e-mails to prospective research supervisors.

Build the A4 PDF with `docs/brief/build.sh` (pandoc, then Chromium through Playwright); the HTML and PDF it writes here are git-ignored.

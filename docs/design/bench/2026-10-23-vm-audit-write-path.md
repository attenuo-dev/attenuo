# End-to-end benchmark, 2026-10-23, vm (perf/audit-write-path)

Commit `38a438d`, release profile, rustc 1.97.0 (2d8144b78 2026-07-07).
Per cell: 2 s warm-up (discarded), 5 s measured, closed loop.

Taken in a shared development container (other agents were compiling on the same 4 vCPUs), with the load generator, proxy and fake upstream on the same cores. Indicative, not a reference machine. Branch perf/audit-write-path: WAL with durability normal and full, group commit, verified-token cache. Load average was 3.2 when the run started and about 6 at the end; the `file_full` one-hop allow cells (434, 1248 and 2176 req/s) coincide with that rise: the same cells measured 765, 3476 and 5710 req/s in a run at commit 78e9b14 an hour earlier.

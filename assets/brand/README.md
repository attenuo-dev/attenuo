# Brand assets

The attenuo mark is the delegation chain: three squares, each smaller than the one before, left to right. A child token holds no more than its parent, and the mark says only that. One colour, no symbol beside the wordmark, never stretched.

| File | Use |
|---|---|
| `mark.svg` | The mark in the brand teal (`#3fc1b0`) for dark backgrounds. |
| `mark-light.svg` | The mark in the light-theme teal (`#0d7468`) for white or light backgrounds. |
| `favicon.svg` | The mark on a teal rounded tile. Browser tabs, app icons, avatars. Also copied to `book-theme/` for the docs site. |
| `header.png` | README header, 1280 by 320 at 2x. |
| `social.png` | GitHub social preview, 1280 by 640. Set under the repository's settings, "Social preview". |

The wordmark is the name set in Bricolage Grotesque 700, tracking -0.02em, always lower case (`attenuo`). Body text in brand material is IBM Plex Sans and code is IBM Plex Mono. Colours, type and spacing are listed in the design system; the PNGs here are rendered from its canvas, so edit there first and re-render rather than editing the PNGs.

Tokens: dark background `#0e1416`, surface `#141c1f`, text `#dce5e7`, muted `#8d9ea3`, accent `#3fc1b0` (light theme `#0d7468`), allow `#5ccf8a`, deny `#f2777a`, warn `#e6b450`.

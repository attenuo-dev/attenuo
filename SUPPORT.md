# Getting help

attenuo is pre-alpha and maintained by one person, so response times are best effort.

- **Questions and design ideas:** [GitHub Discussions](https://github.com/attenuo-dev/attenuo/discussions). Check the [guides](docs/guides/README.md) and the [FAQ](docs/faq.md) first.
- **Bugs:** open an issue with the [bug template](https://github.com/attenuo-dev/attenuo/issues/new?template=bug_report.yml). Include the version or commit, your config with secrets removed, and the audit record or log lines for the decision.
- **Feature requests:** use the [feature template](https://github.com/attenuo-dev/attenuo/issues/new?template=feature_request.yml). Anything that changes the token format, policy request shape, audit schema or public API starts as an RFC; see [docs/spec/README.md](docs/spec/README.md).
- **Security problems:** never in a public issue or discussion. Follow [SECURITY.md](SECURITY.md).
- **Contributing:** [CONTRIBUTING.md](CONTRIBUTING.md).

There is no commercial support and no support SLA.
